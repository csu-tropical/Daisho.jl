Reference State

A hydrostatic reference-density profile ρ̄(z), configured through the optional [reference_state] block and surfaced as ReferenceStateParameters on the loaded DaishoParameters. Shared by consumers that need a base-state density or temperature profile: variational-stage anelastic mass continuity, the radar fall-speed correction, and (a future phase) FHC temperature. See the Reference State guide for the sounding format and worked configuration.

Daisho.ReferenceStateParameters — Type
ReferenceStateParameters

Hydrostatic reference-density profile ρ̄(z), loaded from the optional [reference_state] block. Shared across consumers that need a base-state density or temperature profile: variational-stage mass continuity (∂u/∂x + ∂v/∂y + ∂w/∂z + w·dlnρ̄/dz = 0), radar fall-speed correction, and (in a future phase) FHC temperature. See build_reference_profile, ExponentialReferenceProfile, and SoundingReferenceProfile.

Fields

  • source::String: "exponential" (default) for a simple analytic profile, or "sounding" to build a full hydrostatic reference state from a sounding file via Springsteel (Springsteel.calculate_reference_state).
  • sounding_file::String: path to the sounding file; required (and must exist) when source = "sounding". Format: a surface line p_sfc theta q_v (pressure in hPa, potential temperature in K, water-vapor mixing ratio in g/kg), followed by one z theta q_v line per level (z in metres, q_v in g/kg), matching the samurai/Scythe sounding format.
  • moisture::Bool: sounding source only; when true (default) the reference density includes the vapor partial density (ρ̄ = ρ̄_d + ρ̄_v); when false the state is built dry (ρ̄ = ρ̄_d).
  • density_surface_kg_m3::Float64: exponential source only; surface density ρ₀ in kg m⁻³ (default 1.2).
  • density_scale_height_m::Float64: exponential source only; scale height H in metres (default 8500.0); ρ̄(z) = ρ₀·exp(−z/H).
  • temperature_surface_k::Float64: exponential source only; optional surface temperature T₀ in Kelvin. NaN (the default) means no temperature profile is available — reference_temperature_kelvin and freezing_level_m then return nothing, and temperature_celsius throws.
  • lapse_rate_k_m::Float64: exponential source only; lapse rate Γ in K/m (default 0.0065, the US Standard Atmosphere troposphere value), used only when temperature_surface_k is finite: T(z) = T₀ − Γ·z.

Daisho.AbstractReferenceProfile — Type
AbstractReferenceProfile

Supertype for hydrostatic reference-density profiles ρ̄(z). Concrete subtypes are ExponentialReferenceProfile and SoundingReferenceProfile. Build one from a loaded DaishoParameters with build_reference_profile. Query it with reference_density, dlnrho_dz, reference_temperature_kelvin, freezing_level_m, and temperature_celsius.

source
Daisho.ExponentialReferenceProfile — Type
ExponentialReferenceProfile(rho_surface_kg_m3, scale_height_m,
                             temperature_surface_k, lapse_rate_k_m)

Minimal analytic reference-density profile

ρ̄(z) = ρ₀·exp(−z / H)

with surface density ρ₀ (kg m⁻³) and scale height H (m); z is metres, matching the grid's z-axis/vertical-mish convention (MSL or AGL). Needs no grid — usable anywhere a profile is needed without a sounding.

Optionally carries a linear temperature lapse T(z) = T₀ − Γ·z when temperature_surface_k is finite; NaN (Daisho's convention for "absent") means no temperature profile is available, and reference_temperature_kelvin/freezing_level_m return nothing in that case (temperature_celsius throws).

Built from config via [reference_state] + build_reference_profile.

source
Daisho.SoundingReferenceProfile — Type
SoundingReferenceProfile(file, sgrid; moisture=true)

Hydrostatic reference-density profile built from a sounding file via Springsteel's reference-state machinery (Springsteel.calculate_reference_state), sampled at the vertical mish points of sgrid's k-axis. file is the samurai/Scythe sounding format: a surface line p_sfc theta q_v (pressure in hPa, potential temperature in K, vapor mixing ratio in g/kg), then one z theta q_v line per level (z in metres).

moisture=true (default) includes the vapor partial density in ρ̄ (ρ̄ = ρ̄d + ρ̄v, a MoistReferenceState); moisture=false builds a dry state (ρ̄ = ρ̄_d).

Fields

  • z::Vector{Float64}: vertical mish points (m), ascending.
  • rho::Vector{Float64}: ρ̄ at each mish point (kg m⁻³).
  • drho_dz::Vector{Float64}: dρ̄/dz at each mish point (kg m⁻³ m⁻¹), taken directly from the reference state's spectrally-consistent derivative slot — never finite-differenced.
  • temperature_k::Vector{Float64}: reference temperature (K) at each mish point (Springsteel.reference_temperature).
  • state::Springsteel.AbstractReferenceState: the underlying Springsteel reference state, for callers that need more than density/temperature (entropy, saturation ratio, sound speed, …).

Off-mish queries (reference_density, dlnrho_dz) use cubic Hermite interpolation on (rho, drho_dz) between the bracketing mish levels, clamped to the end values outside [z[1], z[end]].

Reference density ρ̄(z) in kg m⁻³.

Daisho.dlnrho_dz — Function
dlnrho_dz(r::AbstractReferenceProfile, z::Real) -> Float64

d(ln ρ̄)/dz in m⁻¹ — the term the anelastic mass-continuity pseudo-observation needs (w·dlnρ̄/dz). For the exponential profile this is exactly −1/H everywhere; for the sounding profile it is drho_dz(z) / rho(z) from the Hermite-sampled pair.

source
Daisho.reference_temperature_kelvin — Function
reference_temperature_kelvin(r::AbstractReferenceProfile, z::Real) -> Union{Float64,Nothing}

Reference temperature (K) at height z, or nothing when no temperature profile is available. For ExponentialReferenceProfile, nothing when temperature_surface_k is NaN (no temperature configured); otherwise the linear lapse T₀ − Γz. For SoundingReferenceProfile, always available (piecewise-linear interpolation of the stored mish temperatures; never nothing).

source
Daisho.freezing_level_m — Function
freezing_level_m(r::AbstractReferenceProfile) -> Union{Float64,Nothing}

Lowest height (m) at which the reference temperature crosses 273.15 K (0 °C), or nothing when unavailable (no temperature profile) or when the profile never crosses freezing.

For ExponentialReferenceProfile: (temperature_surface_k − 273.15) / lapse_rate_k_m, or nothing when no temperature is configured, the lapse rate is zero, or the crossing would be below the surface (z < 0). For SoundingReferenceProfile: linear interpolation between the first pair of adjacent mish levels whose temperatures bracket 273.15 K.

source
Daisho.build_reference_profile — Function
build_reference_profile(p::DaishoParameters, sgrid) -> AbstractReferenceProfile

Build the reference-density profile configured by p.reference_state, dispatching on p.reference_state.source. The exponential source ignores sgrid entirely (it needs no grid); the sounding source reads p.reference_state.sounding_file on sgrid's vertical mish (see SoundingReferenceProfile).
